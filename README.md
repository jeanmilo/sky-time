# Sky Timer: Time Flies By

A cockatiel shaped countdown timer that perches on your desktop. The bird is
the window — no frame, no rectangle. The countdown lives in its belly. The bird is loosely based off of Skylar's beautiful pet cockatiel.

There are two choices: you could mess with it as a fun program you can remix (aka change code, then use run commands to test it out), or you can download it to use as an app/program for your laptop/puter (installing it).

## How to run it + install

```bash
cd sky-time
npm install
npm start
```

## To install it... ⏰

```bash
cd sky-time
npm install
npm run package
```
